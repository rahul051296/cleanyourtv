# Wallpaper credits

All seven backgrounds are plain colour gradients made for this theme (CC0), with no photos: one for each dock app
and one for the app grid. While an item of the hero carousel is in focus, Home shows that item's own artwork from
your Plex server instead; none of it ships with the theme.

- `youtube.jpg`: a red gradient made for this theme, CC0
- `netflix.jpg`: a red gradient made for this theme, CC0
- `prime.jpg`: a blue gradient made for this theme, CC0
- `plex.jpg`: an amber gradient made for this theme, CC0
- `disney.jpg`: a navy and teal gradient made for this theme, CC0
- `appletv.jpg`: a grey gradient made for this theme, CC0
- `allapps.jpg`: a gradient for the app grid made for this theme, CC0
